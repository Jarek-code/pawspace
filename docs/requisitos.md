# Requisitos

## Software necesario

- Docker
- Docker Compose (viene incluido con Docker)
- Git

## Opcional, para trabajar sin Docker

- Python 3.11 o superior
- Node.js y npm, para el frontend
- MariaDB 11.4 o superior

## Recursos

- 2 GB de RAM como mínimo
- Puertos libres: 3000 (frontend), 8000 (API), 8080 (Adminer) y 3306 (MariaDB)

## Comprobar que están instalados

```bash
docker --version
docker compose version
git --version
```
