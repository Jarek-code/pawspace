# Esquemas

Diagramas del proyecto, en formato PNG y SVG. Los SVG se abren en el navegador y se amplían sin
perder detalle.

## Qué muestra cada uno

| Archivo | Contenido |
|---|---|
| `00-arquitectura-cinco-niveles` | Los cinco niveles de una base distribuida con los procesadores en las flechas |
| `esquema-entidad-relacion` | Modelo relacional: tablas y claves foráneas |
| `01-esquema-local` | Qué hay en cada nodo |
| `02-esquema-componente` | Piezas de cada participante: fragmentos, clases, archivos y colecciones |
| `03-esquema-exportacion` | Qué ofrece cada participante y con qué credencial |
| `04-esquema-federado` | El mismo hecho en los cuatro modelos |
| `05-esquema-externo` | Qué ve cada consumidor y de qué motor sale |
| `06-esquema-asignacion` | Qué vive en cada sitio y cómo se respalda |

Los diagramas se generan con `dot`. Las fuentes no se guardan en el repositorio, así que se editan a
partir del PNG o del SVG que está aquí.
